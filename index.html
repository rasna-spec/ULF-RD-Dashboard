goal

design direction

Build a low-cost, repairable, body-powered pediatric hand that is driven by real child activities, survey evidence, and practical engineering calculations.

Base reference Start from the WAACS / e-NABLE printable arm direction because it is aligned with open-source, standard tools, and low-resource manufacturing. base
Mechanism reference Rebuild and simplify Yale Hand principles only where they improve grasp reliability without adding too much complexity. study
Adaptive reference Study SoftFoot Pro for passive adaptive principles. Integrate only if it stays affordable, repairable, and maintainable. conditional
Design driver Children’s activities, survey responses, object sizes, tendon travel, force estimates, and safety limits must dominate the final design. required
